# Contributing

Thanks for your interest in FinPulse (explore-portfolio).

## Development

Requires [pnpm](https://pnpm.io/). See the project README for app-specific
dev commands.

```bash
pnpm install
pnpm start
```

Useful checks:

```bash
pnpm check-types
pnpm lint
```

## Pull requests

1. Branch from `main` (or the active stack tip for dependent work).
2. Keep changes focused; prefer small PRs with a clear why and test notes.
3. Ensure `pnpm check-types` and `pnpm lint` pass before opening a PR.
4. Open a PR against `main` with a clear description of why the change is
   needed.

## Code of Conduct

Participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
